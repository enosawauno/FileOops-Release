## 💡 关于 FileOops
在整理电脑文件时，你是不是也经常遇到“哎呀（Oops）”又重命名错了、“哎呀”又找不到文件的崩溃瞬间？
**FileOops** 就是为了解决这些痛点而生的。不仅支持多语言（中日韩英等）和多套精美主题配色，还接入了本地 AI 大模型，无需联网即可极速处理你的文件。

目前项目处于 **开发阶段**，功能框架已经搭好，但**非常缺乏极端环境下的测试**。因此，特别需要家人们来抓 Bug 和提建议，也欢迎在群里说出你的需求。

## ✨ 核心功能
- 📦 **批量重命名**：内置 70+ 种规则（常用规则、插入、删除、替换、编号、公式生成等），自由组合。
- 🎨 **格式转换**：图片、音频、视频、文档一键转换格式。
- 🧹 **重复检测**：快速找出电脑里的冗余文件，释放磁盘空间。
- 🧠 **本地 AI 赋能**：接入本地 DeepSeek 模型，支持调用翻译等。
- 🧠 **离线翻译模型**：集成离线翻译引擎，打破网络限制，保障数据安全的同时实现高速翻译。
- 🌍 **多语言支持**：系统语言支持中（简繁）英日韩一键切换。
- 🎭 **多主题换肤**：内置多种主题配色（默认蓝、松石绿、草木绿、金日橙、鹤顶红等），随心切换。
- 🛠️ **其他实用工具**：目录整理、音乐刮削、磁盘可视化、超级分辨率、系统工具等。
